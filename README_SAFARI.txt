ASTRO NUMERICA - proyecto para Safari/iOS (experimental)

1. Instala Python 3.11+ en tu Mac o PC.
2. En Terminal: python3 -m pip install pygbag
3. Abre la carpeta PADRE de AstroNumerica_Safari_Proyecto y ejecuta:
   python3 -m pygbag AstroNumerica_Safari_Proyecto
4. Abre en tu computadora http://localhost:8000
5. Para usarlo en iPhone, publica el sitio generado en build/web usando un hosting HTTPS (por ejemplo itch.io HTML5 o Netlify).
   En algunas versiones de pygbag se genera un archivo .apk web o una carpeta build/web; revisa el resultado de la compilacion.

IMPORTANTE: Esta es una adaptacion inicial, no un juego iOS probado. El texto y las entradas con teclado pueden requerir cambios para iPhone. El guardado usa localStorage del navegador.
